# WorkUp

A workout logger for iPhone that runs as a website. It logs strength, cardio and floor work, and after 14 logged workouts it starts suggesting which muscle group and exercises to train next.

## Use it on your iPhone

1. Open the site in Safari.
2. Tap Share, then **Add to Home Screen**.
3. Open WorkUp from the home screen. It runs full screen and works with no signal.

Your data is stored only on your phone. Use **Settings → Save backup** now and then.

## Hosting

The app is plain static files (`index.html`, `sw.js`, `manifest.json`, icons), so GitHub Pages can serve it: Settings → Pages → Deploy from branch → `main` / root.
